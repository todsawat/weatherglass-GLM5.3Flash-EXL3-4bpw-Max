# Weatherglass

An interactive 3D toy: a miniature living landscape sealed in a brass-and-glass display case. Grab clouds, squeeze rain, shake lightning, blow wind, pour fog, wipe the glass, drag the sun, turn the seasons.

**Live:** https://todsawat.github.io/weatherglass/

![preview](preview.png)

Single self-contained `index.html` — no images, models, fonts or audio files; everything is generated in code. WebGL2 required.

Presets via `?scenario=`: `calm` `rain` `storm` `snow` `mountainsnow` `fog` `autumn` `night` `dusk`

- **Keys** `1`–`5` or `H W C F G` pick a tool, `U` hides the controls.
